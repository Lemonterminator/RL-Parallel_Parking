# 阶段 2 预演：SAC 冒烟测试

这一节记录的是**工程预演**，不是阶段 2 的实验证据。它只回答一个问题：现有物理内核加上 §7 的奖励和 O0 观测，SAC 能不能学到东西。

## 为什么还不是正式阶段 2

- 正式评估集要先用阶段 1 的 Hybrid A* 筛一遍可行性，记录 `L_oracle`，再做哈希冻结（EXIT-2.1、2.2，A26）。Hybrid A* 还没写，所以现在没有冻结评估集。
- §8 要求先冻结评估协议，再做任何调参。所以这次预演**只用 SB3 的默认超参数**（`gamma` 取 `configs/reference.json` 的 0.995），结果不能拿来调参。
- 场景只有一个手工搭的简单平行泊车位（车位长 `1.5·l = 7.05 m`），起点在车位旁边的车道上随机采样，代替 reverse-curriculum 第 0 级。

## 组成

固定下来的数值：

- `R_success = 100`，`P_collision = 40`（出界同样处理），`c_max = 0.05`，EXIT-2.7 下界 17.31，测试里有断言。
- `K = 1.58`：在冒烟起点分布上按 §7.2 一次性标定（2 万个样本，种子 123，原始势函数 p95 = 12.68，使 p95 |Φ(s0)| = 20），之后冻结。
- 成功容差：dx 0.20 m、dy 0.10 m、航向 5°、速度 0.05 m/s；§7.5 没有转角条件，所以转角容差设为执行器上限（不起约束作用）。
- 换挡标记：相邻两步速度异号，且其中一步 |v| ≥ 0.05 m/s，只依赖 (s, s′)，不引入隐藏状态。

## 已知的计划层面问题（留待正式阶段 2 解决）

- §7.4 建议 `w_gear ≲ 1.0`，但 EXIT-2.7、2.28 的 `c_max = 0.05` 要求所有运行代价合计不超过 0.05。两者不能同时满足；预演取 `w_gear = 0.01`。
- 碰撞那一步会“退还” `−Φ(s)`（例如贴着车撞上时 Φ ≈ −25，那一步奖励约 −15 而不是 −40）。这是 `Φ(terminal) = 0` 的正常结果，整段回报里的塑形项仍然收敛到 `−Φ(s0)`，与路径无关，有测试覆盖。

## 在工作站上运行

```powershell
python -m pip install -e ".[rl]"
python -m parking_rl.experiments.smoke_sac --steps 300000 --out runs/smoke_sac
```

一次运行用一个 CPU 环境；想并行就用不同的 `--seed` 和 `--out` 同时开几个进程。

## 第一次预演结果（2026-10-19）：没有学会，原因已定位

工作站上 4 个种子（RTX 5090，SB3 默认参数），各跑约 8 万步后手动终止；容器里另跑了 6 万步 CPU。所有评估成功率都是 0%，超时 95–100%，碰撞 0–4%，智能体学到的策略基本是原地停着等超时。诊断出两个原因：

1. **成功样本从未出现。** 一开始就用最终容差（0.20 m / 0.10 m / 5° / 0.05 m/s，连续 5 步），没有用计划里的容差课程（`PLAN_MACRO.md` 约 1398–1404 行：从 0.60 / 0.40 / 20° / 0.30 自适应收紧），也没有 Stage 1 参考路径支撑的 reverse curriculum。用带惯性的随机动作探索 400 回合：最终容差下 0 次成功；放宽到课程起点容差后有 7 次成功。回放缓冲区里没有成功样本，终端奖励就没有信号可学。
2. **原地不动是一个正回报吸引子。** Φ 处处 ≤ 0、γ < 1 时，停着不动每步得到塑形 `(γ−1)Φ = 0.005·|Φ|`，约 +0.04，比每步运行代价 0.02–0.03 还大。零动作策略在评估种子上的平均回报是 +6.46，和训练出来的策略（2.4–7.6）几乎一样；而随机移动的回合有 83% 以碰撞（−40）结束。理论上 PBRS 不改变最优策略，但在探索不到成功的情况下，这个吸引子决定了学到的策略。要让原地不动不再是净正回报，`w_time` 需要 ≥ `(1−γ)·Φ_clip = 0.15`，但这又和 EXIT-2.7 / 2.28 的 `c_max = 0.05` 冲突，需要在计划层面决定。

结论：按计划的顺序，RL 需要先有 Stage 1 的 Hybrid A* 参考路径（reverse curriculum）和容差课程。这次预演确认了环境、奖励和观测接线可以正常训练，而缺的正是这两块。

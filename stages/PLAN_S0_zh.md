## 手动推导 (Derive by hand)

### (a) 两种单车模型形式及混合使用的缺陷

```
后轴参考点（请使用此形式）：
    x_dot = v cos(theta)
    y_dot = v sin(theta)
    theta_dot = (v / L) tan(delta)

质心（CoG）参考点（距离后轴 l_r，请勿使用）：
    beta = arctan( (l_r / L) tan(delta) )
    x_dot = v cos(theta + beta)
    y_dot = v sin(theta + beta)
    theta_dot = (v cos(beta) / L) tan(delta)
```

使用第一组方程配上 CoG 参考点不是舍入误差 — 请计算本车型的转弯半径偏差值并记录在笔记中。[§5.0(a)]

### (b) 双圆弧横向平移（平行停车 S 曲线）

转角为 φ、半径为 R 的两个相反全打满圆弧：

```
横向增益     d    = 2R (1 - cos phi)
纵向行程     ell  = 2R sin phi
消去 phi:    ell  = sqrt(4Rd - d^2)          在 d <= 2R 时有效
```

在 R = 3.9466 m, d = 2.35 m 下评估 → ell = **5.62 m**。请注意这代表什么：这是**横向平移关系**，而非最小车位长度公式。它给出了侧向平移 d 所需的纵向行程；车位长度还需要考虑车身长度、悬长以及对前后邻车的避障条件。[§5.0(b)]

> **5.62 m 是理想转向值，你的车辆无法执行它。** 双圆弧构造要求在连接点处从 `+delta_max` *瞬时*反转至 `−delta_max` — 这正是 §5.1 指出的最坏情况非尖点 C→C 连接。仿真实际受速率限制的 S 曲线（δ 以 0.6 rad/s 倾斜，平分保持时间以实现 2.35 m 净平移，最终航向角为 0）：
>
> ```
> v = 0.5 m/s : 纵向 6.179 m (+0.560 m, +10.0%),  路径长度 6.802 m
> v = 1.0 m/s : 纵向 6.792 m (+1.173 m, +20.9%),  路径长度 7.388 m
> v = 1.5 m/s : 仅斜坡段就超调了 2.35 m 平移（零保持）— 此形式无解
> ```
>
> 仅将 `sqrt(4Rd − d²)` 用作**下界**。请注意 EXIT-0.7 仅校验理想圆弧积分代数；可执行性检查属于阶段 1（EXIT-1.8）。[§5.0(b)]

### (c) 最小平行停车车位长度 — 请自行推导

文献中有已知的闭式解。**本计划故意不复现。** 两个独立的 Agent 得出了相同的结论：已发表的公式在“长度”是否包含悬长、参考点是后轴还是车身中心上不一致（在 f = 0.9, r = 1.1 时，约定差异超过一米）。凭记忆写出的公式将是伪造的。[§5.0(c)]

推导框架设定如下：

```
坐标系：邻车在 y 轴占据 [y_k, y_k + w_p]；自车最终停放位姿航向角为 0，
后轴位于 (0,0)，车身占据 x ∈ [-r, L+f] = [-1.1, 3.6]，y ∈ [-w/2, +w/2]。
自车从车道以航向角 0 开始，横向偏移 Δ = w + c_lat。
两个相同的全打满圆弧，航向角 0 -> -phi -> 0，半径均为 R = R_min:
    Delta = 2R(1 - cos phi)                     求解 phi
    纵向延伸 = 2R sin phi
然后分别列出不等式：
    (i)   在第一段圆弧中，后车身角点避开后方邻车
    (ii)  靠马路牙侧的前角点避开前方邻车                  <- 见下文警告
    (iii) 最终停放的车身以间隙 c_end 容纳于两车之间
    (iv)  靠车道侧的前角点 (R_front_outer = 6.0574 m) 不侵入相邻车道 <- v1.0 遗漏了此项
```

[§5.0(c)]

> **推导前先固定坐标系。** 明确马路牙位置（假设 +y），固定 φ 的符号，在坐标系中标注四个角点半径，然后再写不等式。条件 (iv)（对车道侧的避障）是真实约束。EXIT-0.8 将门控整个车位长度推导。[§5.0(c)]

然后**数值验证闭式解**：使用限制单尖点的 Hybrid A* 对车位长度进行二分查找，要求在一个网格单元分辨率内与闭式解吻合。[§5.0(c)]

### (c′) 倒车入库几何 — 完全闭式解 *(v1.3 新增)*

倒车入库的单切割边界（Single-cut boundary）在后轴坐标系下存在精确闭式解，且**完全由 §4 已汇总的三个半径表达**。[§5.0(c′)]

**坐标系定义：**

```
车位中心线          x = 0                    车位口线         y = 0
车位内部            -D_bay <= y <= 0         目标车位         |x| <= W_bay/2
通道                0 <= y <= W_aisle        远端：y = W_aisle 处的硬墙
邻车                |x| >= W_gap/2 且 y <= 0 的区域全为障碍物
目标位姿            后轴 (0, y_goal)，theta = +pi/2      <- 车头朝外（Nose OUT）
驶入方式            自车以 theta = 0 沿通道向上行驶，车位在其右侧
```

向右倒车入库会使**后右侧**摆动，航向角逆时针旋转 0 → +π/2。[§5.0(c′)]

> **`W_gap` 不是 `W_bay`，两者差异对应 0.69 m 的通道宽度。**
> ```
> 墙壁 / 标线，不允许侵入               : W_gap = W_bay        = 2.50 m
> 两侧邻车均居中停放在相同车位中          : W_gap = 2*W_bay - w  = 3.15 m
> ```
> A27 声明 `W_gap` 为场景参数，默认采用墙模型。[§5.0(c′)] [A27]

**操作过程：** 单切割 = 一次换挡：（1）沿通道以航向角 0 前行；（2）**一段倒车圆弧**（半径 `R`，航向角 0 → π/2，旋转中心 `C = (x_e + R, y_c)`）；（3）直线倒车沿 `x = x_e` 进入车位。自由参数为 `y_c` 与 `x_e`。[§5.0(c′)]

**步骤 1 — 转换到旋转中心坐标系：** 令 **`u = −y_c`**（旋转中心低于车位口线的距离）。距 `C` 最远点为前外角点（半径 `R_front_outer`），故：

```
整个操作过程的最大 y = y_c + R_front_outer  =>   W_aisle = R_front_outer - u
```

通道越窄意味 `u` 越大。[§5.0(c′)]

**步骤 2 — 扫过区域在车位排内部留下的轮廓（Footprint）：** 在旋转中心坐标系下（高度 `eta <= u`）：

```
右边界  X_max(u) = -sqrt( R_swept_inner^2 - max(u,0)^2 )     <- 内侧包络圆
左边界  X_min(u) = -sqrt( R_rear_outer^2  - min(u,0)^2 )     <- 后外角点圆
轮廓宽度 F(u) = X_max(u) - X_min(u)
```

[§5.0(c′)]

**步骤 3 — 可行性单标量不等式：** 设两侧与邻车的安全间隙为 `c`，令 `W' = W_gap - 2c`，存在可行 `x_e` 的**充分必要条件为 `F(u) <= W'`**。反求得：

```
u*  = + sqrt( R_swept_inner^2 - (R_rear_outer - W')^2 )     若 W' >= R_rear_outer - R_swept_inner
    = - sqrt( R_rear_outer^2  - (R_swept_inner + W')^2 )     若 w <= W' <  R_rear_outer - R_swept_inner
      上限截断于 u* <= R_swept_inner - c

W_aisle_min = R_front_outer - u*

x_e* = R_rear_outer - R - W_gap/2 + c        (上分支)
     = W_gap/2 - c - w/2                     (下分支)
```

[§5.0(c′)]

**基准场景下的数值设计表（`R = R_min` 且采用墙模型 `W_gap = W_bay`）：**

```
W_bay | W_aisle_min (对应侧向间隙 c)                | 6.00 m 通道能买到的
      |  c=0      c=0.10    c=0.20    c=0.30         | 侧向间隙
------+---------------------------------------------+------------------------
 2.30 | 4.690     5.189     6.906     不可行          | 0.163 m
 2.40 | 4.508     4.908     5.652     不可行          | 0.213 m
 2.50 | 4.352     4.690     5.189     6.906          | 0.263 m   <- 基准场景
 2.60 | 4.214     4.508     4.908     5.652          | 0.313 m
 2.80 | 3.980     4.214     4.508     4.908          | 0.413 m
 3.00 | 3.787     3.980     4.214     4.508          | 0.513 m
```

[§5.0(c′)]

> **通道宽度买到的侧向摆动间隙无法超过 `(W_bay − w)/2`**（基准车位下为 0.325 m）。饱和点位于 `W_aisle = R_front_outer + r = 7.1574 m`。[§5.0(c′)]

**静态包容性下界（Static Containment Bound）：** 对于基准车位，真实多切割边界位于 **[3.5100, 4.3519]** 之间。阶段 1 规划器返回超出该范围的结果均属 Bug（EXIT-0.10）。[§5.0(c′)]

**目标位姿与朝向陷阱：** 居中停放目标位姿为 `goal = (0, -3.90, +pi/2)`。[§5.0(c′)]

> **禁止使用双角点匹配（Two-corner matching）：** `theta = -pi/2` 为车头朝内（Nose-in），开启双角点匹配会将“倒车入库”隐式变为“驶入车位”，破坏对比基线。**EXIT-0.15 强制要求拒绝车头朝内位姿。**[§5.0(c′)]

**难度轴：** 车位族的难度标量为**通道松弛比** `eta_bay = W_aisle / W_aisle_min(W_gap; R_min, c = 0)`。[§5.0(c′)]

### (d) OBB–OBB 精确 signed distance

```
情况 1 — SAT 汇报重叠：
    signed_distance = -penetration_depth
                    = -min over candidate axes of (projection overlap)
    矩形只需 4 个候选轴（各自的 2 个法线）；2D 最小平移距离必定沿法线方向。

情况 2 — SAT 汇报分离：
    d(A,B) = min over all (vertex v of A, edge e of B) of point_segment_dist(v, e)
             与 (vertex v of B, edge e of A)
           = 两个矩形共 32 次点-线段评估。极轻量，易向量化。
```

**关键：** SAT 法线缝隙仅为真实分离距离的**下界**（在顶点-顶点相近时会严重低估）。绝不能将 SAT 缝隙作为清除度量。遇到包含情况时，先运行 SAT。[§5.0(d)]

### (e) 多圆车身近似及其保守性

4.7 × 1.85 m 车身分为 3 个等距圆，覆盖半径为 $\rho = 1.2121\text{ m}$，比真实半宽 0.9250 m 侧向多估计了 **0.2871 m**。

**分工原则：**
- 3 圆模型 → **Reward 势能中的平滑安全边际项**（快速、可微）
- 精确 OBB → **终止判定及所有汇报的间隙 Metric**

[§5.0(e)]

### (f) 连续碰撞检测分辨率 (CCD)

在相隔 $\Delta s$ 及航向变化 $\Delta\theta$ 的两采样点间，最远点位移 $\le \Delta s + d_{\max}|\Delta\theta| \le \Delta s(1 + d_{\max}\kappa_{\max}) = 1.9419 \Delta s$。

若保证位移 $\le \epsilon = 0.05\text{ m}$，需 $\Delta s \le 0.0258\text{ m}$。障碍物厚度不得小于 ~0.09 m。[§5.0(f)]

### (g) 位姿误差度量 (Pose-error metrics)

采用 `(1 − cos Δθ)` 代替 `Δθ²`。倒车入库起始航向误差大，`1 - cos Δθ` 在 180° 处梯度消失（Gradient Plateau）。**§7.3 改用 `1 − cos(Δθ/2)` 形式，必须采用此形式。**[§5.0(g)]
